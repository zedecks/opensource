# ZEDECK Open Source

> Este repositório é parte da organização técnica da Zedeck's IT — ver visão geral da org em [zedecks/opensource](https://github.com/zedecks/opensource) (site-vitrine) e stack de identidade em [zedecks/design-system](https://github.com/zedecks/design-system).

Vitrine oficial e portal curado de iniciativas, bibliotecas e projetos de código aberto da **Zedeck's IT**.

---

## 🌟 Projetos & Iniciativas Abertas

Uma seleção de ferramentas, utilitários e especificações mantidos pela Zedeck's IT para a comunidade de desenvolvedores:

* **`mozdev-platform`:** Plataforma comunitária e ecossistema digital aberto para desenvolvedores moçambicanos.
* **`core-sdk` *(Camadas Públicas)*:** SDKs e bibliotecas cliente em TypeScript, Kotlin e PHP para autenticação OIDC via Conta Zedecks.
* **`design-system` *(Tokens & UI Neutra - Futuro)*:** Especificações de tokens e componentes de design reutilizáveis.

---

## 🎯 Critérios de Inclusão na Vitrine

Para que um projeto ou biblioteca seja listado nesta vitrine oficial, deve cumprir os seguintes critérios:

1. **Propósito Claro:** Resolver um problema real da comunidade técnica ou fornecer uma integração oficial segura com nossos serviços.
2. **Licenciamento Formal:** Licença permissiva explícita (ex: MIT, Apache 2.0) sem restrições proprietárias.
3. **Documentação & Exemplos:** `README.md` completo, guia de instalação e cobertura de testes automatizados.
4. **Sem Lógica de Negócio Fechada (Regra R6):** Este repositório é estritamente uma vitrine/catálogo, nunca fonte de lógica de negócio proprietária.
